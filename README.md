# FoodEase — Restaurant Ordering Application

**Project Management Portfolio | Hypothetical IT Project Simulation**

## Project Overview

FoodEase is a simulated software development project involving a digital restaurant ordering application for a hypothetical restaurant chain operating 10 outlets.

The proposed application enables customers to select an outlet, browse menus, manage their cart, make online payments, place orders and track order status. Restaurant staff can manage incoming orders through a dedicated dashboard.

The project is planned around a controlled pilot at two outlets before considering a wider rollout.

## My Role

**Simulated Role:** Project Coordinator / Junior Project Manager

This portfolio demonstrates how I would coordinate a software development project across initiation, planning, requirements gathering, Agile execution, quality assurance, release management and project closure.

## Project Lifecycle and Documentation

### 01 — Project Initiation
Project Charter, Project Scope Statement and Stakeholder Register.

### 02 — Project Planning
Project Management Plan, Work Breakdown Structure, Project Schedule, Risk Register, Communication Plan and Change Control Process.

### 03 — Requirements and Design
Business Requirements Document (BRD), Functional Requirements Document (FRD), Software Requirements Specification (SRS), User Stories, Acceptance Criteria and Requirements Traceability Matrix (RTM).

### 04 — Agile and Execution
Agile Operating Model, Product Backlog, Sprint Plans, Sprint Reviews and Retrospectives.

### 05 — Testing and Quality Assurance
Test Plan, Test Cases, Defect Log, UAT Report and UAT Sign-off Template.

### 06 — Release and Deployment
Release Plan, Deployment Checklist, Rollback Plan, Release Notes and Post-Release Monitoring Plan.

### 07 — Project Closure
Project Closeout Report, Lessons Learned Register and Operational Handover Checklist.
